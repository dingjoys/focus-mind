## 1. 问题与机会

### ADHD 的核心困境

注意缺陷多动障碍（ADHD）全球患病率约 **5-7%**，成人患者超过 **3.66 亿**。他们面临的核心挑战不是能力不足，而是**执行功能障碍**：

- **任务启动困难**：知道要做什么，但就是无法开始
- **优先级判断失效**：所有事情感觉同等紧急或同等不重要
- **选择困难**：面对选项时大脑"当机"，消耗大量时间和情绪
- **时间感知扭曲**（Time Blindness）：严重低估或高估任务所需时间
- **情绪调节障碍**：挫败感、焦虑感循环，进一步破坏执行力
- **碎片化日程**：任何打断都可能导致当天计划全面崩塌

### 现有工具的失效原因

现有生产力工具（Notion、Todoist、Tiimo 等）**为神经典型（Neurotypical）用户设计**，要求用户具备稳定的自我规划能力，这恰恰是 ADHD 人群最缺乏的能力。

> "我知道 Notion 很强大，但我花了 3 小时配置模板，然后再也没打开过它。"  
> — 典型 ADHD 用户反馈

## 2. 目标用户

### 核心用户画像

**主要人群：成人 ADHD 患者（18-45 岁）**
- 已确诊或疑似 ADHD
- 有改善生活效率的强烈意愿
- 对 AI 工具接受度高
- 主要分布于一线/二线城市及海外华人群体

**次要人群：**
- 执行功能较弱但未确诊的人群（拖延症、焦虑症人群）
- ADHD 儿童的家长（协助制定孩子日程策略）
- 职场高压人群（需要外部结构支持）

### 用户痛点优先级

| 痛点 | 频率 | 情绪强度 | 现有解决方案 |
|------|------|---------|-------------|
| 不知道今天从哪里开始 | 每日 | 极高 | 无效 |
| 选择困难，需要他人建议 | 高频 | 高 | 无 |
| 计划总被打断后无法恢复 | 高频 | 高 | 无 |
| 任务太大不知如何分解 | 中频 | 中 | 部分 |
| 忘记重要事项 | 高频 | 高 | 提醒类工具 |

| AI 对话式规划 | ❌ | 基础 | 基础 | ❌ | ✅✅ |
| 每日策略生成 | ❌ | ❌ | ❌ | ❌ | ✅ |
| 大语言模型集成 | ❌ | ❌ | ❌ | 部分 | ✅✅ |
| 选择困难辅助 | ❌ | ❌ | ❌ | ❌ | ✅ |
| 日程可视化 | ✅✅ | ✅ | ✅ | ❌ | ✅ |
| 任务分解 | ❌ | ❌ | ❌ | ✅ | ✅✅ |
| 情绪感知调整 | ❌ | ❌ | ❌ | ❌ | ✅ |
| 打断恢复机制 | ❌ | ❌ | ❌ | ❌ | ✅ |
| 月费（USD） | $4.99 | $3.99 | $8 | 免费 | $9.99 |

### 竞品核心缺陷

**Tiimo**：视觉化做得好，但完全没有 AI 能力，需要用户自己规划好再输入，对 ADHD 用户来说这一步已经是最难的了。

**TickTick**：功能完善但为普通用户设计，AI 只是辅助标签分类，无法理解 ADHD 的执行障碍语境。

**Notion AI**：通用 AI 写作助手，不理解 ADHD，无法生成个性化的每日执行策略。

**Goblin Tools**：Magic ToDo 功能（任务分解）对 ADHD 友好，但功能单一，没有持续对话能力和日程整合。

### FocusMind 差异化核心

> **从"工具"到"AI 副驾驶"**  
> 竞品要求用户自己想清楚再输入；FocusMind 通过对话帮用户想清楚。

## 4. 产品方案

### 产品理念

FocusMind 的核心不是任务管理，而是**决策卸载（Decision Offloading）**——将 ADHD 用户最消耗认知资源的"想清楚该做什么"这一步，外包给 AI Agent。

### 三大核心体验

#### 体验一：晨间策略对话（Morning Strategy Session）

用户起床后，FocusMind 主动发起对话：

```
FocusMind: 早上好！今天感觉怎么样？(1-5 分)

用户: 3分，还行，有点焦虑

FocusMind: 明白了。我看到你今天有 6 件待办：
  · 提交项目报告（deadline 今天 6PM）
  · 回复王总邮件
  · 预约牙医
  · 超市采购
  · 准备周会PPT（周四）
  · 整理书桌

基于你现在的状态（3/5），我建议今天的策略是：

  🔴 必须完成：项目报告（2小时专注块 + 1小时缓冲）
  🟡 顺手做：回复王总邮件（10分钟）
  🟢 今天不做：其余4项移到明天

要按这个来，还是有什么想调整的？
```

#### 体验二：实时决策支持（On-demand Advisory）

任何时刻用户可以呼唤 FocusMind：

```
用户: 我现在卡住了，不知道该继续写报告还是先去吃午饭

FocusMind: 你上次吃东西是什么时候？

用户: 早上8点

FocusMind: 现在12:30，4.5小时没吃东西了。ADHD 状态下血糖低会让专注变得更难。

建议：先去吃饭（30分钟），回来后报告应该更好写。
吃饭时把手机放包里，让大脑真正休息。

要我在30分钟后提醒你回来继续吗？
```

#### 体验三：打断恢复（Interruption Recovery）

当日程被打断后：

```
FocusMind: 检测到你离开了报告任务 45 分钟。
现在是 3:15 PM，报告 deadline 是 6:00 PM。

你还有 2小时45分钟，这是足够的。

上次你写到了第三章结论部分。
接下来的20分钟，你只需要完成结论段落的第一句话。

准备好了吗？
```

## 5. 核心功能

### MVP 功能集（第一阶段）

#### 5.1 AI 对话式策略规划

- **晨间 Check-in**：情绪状态评估 + 当日任务盘点
- **优先级智能排序**：基于 deadline、情绪状态、任务复杂度自动排序
- **时间块生成**：将任务分配到具体时间段，预留缓冲和休息时间
- **策略说明**：每个建议都附带简短的"为什么"，帮助用户理解和接受

#### 5.2 大语言模型对话能力

- **多模型支持**：Claude、GPT-4、Gemini 可选（用户可配置）
- **ADHD 语境优化**：系统提示词针对 ADHD 特征定制，模型以"执行副驾驶"角色交互
- **选择困难解决器**：帮用户在选项间做决定，给出具体建议而非罗列利弊
- **任务分解**：将模糊大任务分解为可立即执行的小步骤（最小可操作单元）
- **情绪支持**：识别用户挫败情绪，给予适度肯定和重新框架（Reframing）

#### 5.3 日程与任务管理

- **简单任务录入**：支持语音、自然语言输入（"明天下午3点有个会"）
- **日历视图**：时间块可视化，色块标注任务类型和优先级
- **提醒系统**：渐进式提醒（提前15分钟、5分钟、开始时）
- **完成打卡**：简单的完成记录，每完成一项给予正向反馈

#### 5.4 专注模式

- **番茄钟集成**：可配置时长的专注计时器
- **干扰屏蔽提示**：专注时段建议关闭通知
- **进度可见化**：实时显示剩余时间和完成比例

### 进阶功能集（第二阶段）

- **模式识别**：分析用户数据，识别高效时段、常见卡点
- **Proactive Agent**：主动在合适时机发起对话（如检测到用户超过15分钟无操作）
- **日历集成**：与 Google Calendar、Apple Calendar 双向同步
- **外部工具接入**：读取 Notion/Todoist 任务列表，统一在 FocusMind 中规划
- **家庭/支持者模式**：允许信任的人（伴侣、治疗师）查看日报和配合制定策略

### 关键技术选型

| 层次 | 技术选型 | 理由 |
|------|---------|------|
| 前端 | React Native (Expo) | 跨平台，快速迭代 |
| 后端 | Node.js + TypeScript | 团队熟悉，生态完善 |
| AI 层 | Anthropic Claude API（主）+ OpenAI 备选 | Claude 在对话理解和细腻表达上更适合辅助角色 |
| 数据库 | PostgreSQL + Redis | 任务持久化 + 会话缓存 |
| 实时通信 | WebSocket | 流式 AI 回复，无感知延迟 |
| 推送通知 | FCM + APNs | 跨平台提醒 |
| 认证 | Clerk / Auth0 | 快速接入 |

### AI 策略引擎设计

```
用户输入（情绪 + 任务列表 + 历史偏好）
         ↓
   [上下文构建器]
   · 当前时间 / deadline 距离
   · 用户历史执行模式
   · 当日情绪评分
   · 任务优先级规则
         ↓
   [LLM 推理层] — Claude / GPT-4
   · System Prompt: ADHD Coach 角色定义
   · Few-shot: ADHD 友好策略示例
   · Chain-of-Thought: 显式推理过程
         ↓
   [结构化输出解析]
   · 策略 JSON → 前端渲染
   · 时间块 → 日历组件
   · 优先级标签 → 颜色编码
```

## 9. Go-to-Market 策略

### 第一阶段：社区冷启动（0-6 个月）

**目标**：1,000 核心用户，净推荐值（NPS）> 50

- **Reddit/小红书/Discord 渗透**：在 ADHD 相关社区真实分享产品，参与讨论，收集反馈
- **ADHD 博主合作**：邀请 10-20 位 ADHD 内容创作者内测，换取真实使用评测
- **免费早期访问**：前 500 用户永久免费 Pro，建立口碑基础
- **内容营销**：发布"ADHD 生产力指南"等实用内容，SEO + 社区传播

### 第二阶段：口碑扩张（6-18 个月）

**目标**：10,000 用户，3% → 8% 付费转化

- **推荐奖励计划**：推荐一位成功付费用户，双方各获得1个月免费 Pro
- **App Store 优化**：关键词优化，争取"ADHD"相关词汇的首页排名
- **与心理咨询师合作**：提供专业版（降价），咨询师推荐给患者
- **媒体报道**：投递 TechCrunch、少数派、36氪等科技媒体

### 第三阶段：规模化（18-36 个月）

**目标**：50,000 用户，10%+ 付费转化

- **付费获客**：基于前两阶段数据，投放 Facebook/Instagram/小红书精准广告
- **企业合作**：与 ADHD 诊所、学校辅导中心、企业 EAP 项目合作
- **海外扩张**：英语市场（美国、英国、澳大利亚）并行推进

## 附录：产品核心设计原则

1. **最少输入，最大价值**：ADHD 用户不擅长长篇填写，所有输入界面以1-3步完成为目标
2. **即时正向反馈**：每完成一个动作立即给予视觉/声音反馈，激活多巴胺回路
3. **不评判（Non-judgmental）**：语言永远温和、接纳，永不催促或批评
4. **可见进度**：所有等待和进度必须可视化，减少时间感知扭曲带来的焦虑
5. **可逆操作**：所有操作都可以轻松撤销和修改，降低决策压力
6. **单一焦点**：界面每次只呈现一件最重要的事，避免信息过载
